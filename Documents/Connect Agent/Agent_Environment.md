# PRIBIT Connect Agent Application 설치 환경 안내

이 문서는 PRIBIT Connect Agent Application을 설치하기 위한 최소 시스템 사양 및 권장 하드웨어, 소프트웨어 환경을 안내합니다.

## PC

#### 최소 시스템 사양

- **CPU**: Intel Core i3 이상
- **메모리**: 4GB RAM 이상
- **저장공간**: 20GB 이상의 여유 공간
- **NIC**: 10/100/1000 Base-TX RJ45 포트 1개 이상  
- **운영체제**:  
  - Windows 10 Pro (32/64 bit)  
  - Mac OS 10.12 Sierra 이상  

#### 권장 사양

- **CPU**: Intel Core i5 이상 또는 동급의 AMD 프로세서  
- **메모리**: 8GB RAM 이상  
- **저장공간**: 50GB 이상의 여유 공간  
- **NIC**: 10/100/1000 Base-TX RJ45 포트 1개 이상  
- **운영체제**:  
  - Windows 11 (32/64 bit)  
  - Mac OS 15 Sequoia 

#### 소프트웨어 환경

- .NET Framework 4.8 이상
- 최신 보안 업데이트 적용
- (Windows) 관리자 권한 필요


## Mobile 

#### 최소 시스템 사양

- **CPU**: 1.4GHz 이상  
- **메모리**: 2GB 이상    
- **저장공간**: 1G 이상의 여유 공간   
- **데이터 통신 속도**: 최소 400kbps 이상 
- **운영체제**:  
  - Android: 8.0 
  - iOS: 12 버전 이상 (iPhone 6S 이상 지원)


#### 권장 사양

- **CPU**: 1.4GHz 이상  
- **메모리**: 4GB 이상    
- **저장공간**: 10G 이상의 여유 공간   
- **데이터 통신 속도**: 100 Mbps 이상 
- **운영체제**:  
  - (2025년 8월 최신 버전 기준)
  - Android: 15 
  - iOS: 18.6.2 (iPhone 16)
