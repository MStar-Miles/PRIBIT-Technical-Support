이 문서는 Pribit Connect에서 인사 데이터 연동을 위한 3가지 방법(DB to DB, AD/LDAP to DB, API 연동)에 대한 단계별 절차를 안내하는 가이드입니다.

각 연동 방식별로 필요한 준비 사항, 설정 방법, 테스트 및 운영 환경에서의 모니터링까지의 전체 프로세스를 상세하게 설명합니다.

- DB to DB 연동: 데이터베이스 간 직접 연결을 통한 인사 데이터 동기화 절차 안내
- AD/LDAP to DB 연동: AD/LDAP 서버와의 연동을 통한 인사 데이터 매핑 및 동기화 절차 안내
- API 연동: RESTful API를 활용한 실시간 인사 데이터 연동 절차 안내

각 절차는 실제 환경에서 적용 가능한 단계별 가이드로 구성되어 있습니다.

Pribit Connect에서 계정 연동은 다음의 3가지 방법으로 진행할 수 있습니다.

1. **DB to DB**  
    데이터베이스 간 직접 연동을 통해 인사 정보를 주고받는 방식입니다.

2. **AD (LDAP) to DB**  
    Active Directory(AD) 또는 LDAP 서버에서 PCC DB로 인사 정보를 동기화하는 방식입니다. 
    
    **절차 안내**
    1. AD/LDAP 서버의 연결 정보(호스트, 포트, 인증 정보 등)를 준비합니다. 
    2. Pribit Connect에서 AD/LDAP 연동 모듈을 활성화합니다. 
    3. AD/LDAP에서 필요한 인사 속성(예: 이름, 부서, 이메일 등)을 매핑합니다. 
    4. 동기화 주기 및 방식(수동/자동)을 설정합니다. 
    5. 테스트 동기화를 통해 데이터가 정상적으로 연동되는지 확인합니다. 
    6. 운영 환경에서 정기적으로 동기화가 이루어지도록 모니터링합니다. 

3. **API 연동**  
    RESTful API를 활용하여 인사 데이터를 실시간으로 연동하는 방식입니다.

    **절차 안내**
    1. API 연동을 위한 엔드포인트(URL), 인증 방식(Token, OAuth 등)을 준비합니다. 
    2. Pribit Connect에서 API 연동 모듈을 활성화합니다. 
    3. 인사 데이터의 필드 매핑 및 변환 규칙을 설정합니다. 
    4. API 호출 주기 및 오류 처리 정책을 정의합니다. 
    5. 샘플 데이터를 이용해 API 연동 테스트를 진행합니다. 
    6. 운영 환경에서 실시간 데이터 연동 및 모니터링을 수행합니다.
